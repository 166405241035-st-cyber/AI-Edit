## หลักการใช้บันทึกนี้

บันทึกนี้สรุปจากการทำงานจริงหนึ่งโปรเจกต์ ไม่ใช่ข้อสรุปถาวรเกี่ยวกับตัวผู้ใช้ ให้คำสั่งล่าสุดและบรีฟของงานใหม่มีน้ำหนักมากกว่าความชอบที่บันทึกไว้เสมอ

แยกคำขอที่ระบุชัดเจนออกจากข้อสังเกตของ AI ไม่ถือว่าสิ่งที่ AI เสนอหรือค่าที่ใช้ในโปรเจกต์นี้เป็นความชอบถาวรโดยอัตโนมัติ

เอกสารนี้เก็บสรุปงานและแนวทาง ไม่ได้แนบภาพต้นฉบับ ไฟล์เสียง วิดีโอ หรือซอร์สโปรเจกต์ Remotion ไฟล์สื่อยังอยู่ในเครื่องของผู้ใช้

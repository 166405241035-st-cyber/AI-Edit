## หลักการใช้บันทึกนี้

บันทึกนี้สรุปจากงาน Halloween และ MV Sweet Talk ซึ่งมีธีมต่างกัน ไม่ใช่ข้อสรุปถาวรเกี่ยวกับตัวผู้ใช้ ให้คำสั่งล่าสุดและบรีฟของงานใหม่มีน้ำหนักมากกว่าความชอบที่บันทึกไว้เสมอ

แยกคำขอที่ระบุชัดเจนออกจากข้อสังเกตของ AI ไม่ถือว่าสิ่งที่ AI เสนอหรือค่าที่ใช้ในโปรเจกต์นี้เป็นความชอบถาวรโดยอัตโนมัติ

เอกสารนี้เก็บสรุปงานและแนวทาง ไม่ได้แนบภาพต้นฉบับ ไฟล์เสียง วิดีโอ หรือซอร์สโปรเจกต์ Remotion ไฟล์สื่อยังอยู่ในเครื่องของผู้ใช้

## งานล่าสุดที่ควรเริ่มต่อ

Sweet Talk ใช้ `SweetTalk-Full-B` เป็นเวอร์ชันปรับล่าสุด โดยเก็บ A และตัวเดิมไว้เทียบ มี MP4 พรีวิว 540p พร้อมเสียงเรนเดอร์แล้ว แต่ยังไม่มีหลักฐานว่าผู้ใช้ดูและยืนยันไฟนอล ให้ดูรายละเอียดในบันทึกเซสชันก่อนเริ่มเรนเดอร์ใหม่

AI ที่ทำต่อควรอ่าน `AGENTS.md` และกติกาโควต้าก่อน: เสนอแผนก่อนแก้ และถ้าทำไปแล้วเริ่มมีแนวโน้มใช้โควต้าเยอะ ให้หยุดถามพร้อมทางเลือก ไม่วนตรวจสถานะถี่จนสิ้นเปลือง

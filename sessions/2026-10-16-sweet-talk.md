## เส้นทางการตัดสินใจที่สำคัญ

1. ร่างแรกชมพูฟุ้ง ตัวละคร/ข้อความนิ่ง → ลดความฟุ้ง ใช้เลเยอร์ PSD และเพิ่มโมชั่น
2. ทดลอง 20 วินาที ผู้ใช้ชอบลำดับกรอบภาพที่เลื่อนลงเจออีกกรอบ และอยากมีฉากเต็มจอด้วย
3. เก็บ 20 วินาทีแรกไว้ เอาข้อความหัวเรื่องที่ทับร้องและหลอดโหลดออก ต่ออีก 20 วินาที พร้อมเล่นมุมกล้อง
4. ซูมเข้าผ่าน แต่ซูมออกโล่ง → เติมระยะหน้า/พร็อพ ฉากยังต้องรองรับข้อความ
5. ปฏิเสธข้อความแบบคอลัมน์/สไลด์เลื่อน → เปลี่ยนเป็นกลุ่มคำหลายตำแหน่งในฉาก ผู้ใช้บอกว่าดูดี
6. ขอเด้งตรงร้องตั้งแต่คำแรก แล้วภายหลังขอเริ่มก่อนเสียง 0.15–0.2 วินาที
7. อนุมัติให้ลองตัวเต็ม เพิ่มทรานซิชันหลายแบบและโมชั่นช่วงฮุก แต่ปฏิเสธแสงวาบ และต่อมาปฏิเสธทรานซิชันแสงทั้งหมด
8. ชี้แจงว่าต้องขยับชิ้นส่วน ไม่ใช่เด้งทั้งตัว; 3:10 «พอได้»
9. แก้เฉพาะ 1:36 เป็นน้องชมพูปาด และเฉพาะจุดแสงเป็นอย่างอื่น ไม่ใช่เปลี่ยนทั้งหมด
10. อนุมัติกระดาษครีม / «จริงเหรอ?» แทนคำ «โม้» พื้นม่วง
11. ขอ A ตามคำขอ และ B เพิ่มไอเดีย AI เพื่อเทียบ
12. กระดาษหมุนที่แทนแสงไม่ผ่าน → ผู้ใช้ให้ปรับเฉพาะ B เป็นกล้องเชื่อมฉาก โดยปรับท้าย–ต้นฉากให้เข้ากันด้วย พร้อมข้อความสมูท ผสมคำและประโยค
13. พรีวิว Studio FPS ต่ำมาก → ผู้ใช้อนุมัติ MP4 พรีวิว 960×540 / 30 fps เต็มเพลง
14. ระหว่างเรนเดอร์มีการตรวจสถานะถี่และใช้โต้ตอบมาก ผู้ใช้กำหนดให้ถามก่อนเมื่อมีแนวโน้มใช้โควต้าเยอะ พร้อมเสนอทางเลือกแก้ปัญหา

## ปัญหา/ข้อควรระวังทางเทคนิค

- เคยเรนเดอร์ผ่านเบราว์เซอร์แล้วเสื้อ แขน และเค้กหายทั้งเลเยอร์ สาเหตุสัมพันธ์กับ CSS `maskImage` ของ body PNG
- แก้โดยใช้ `public/art/rig/part-4-feathered.png` ที่ฝัง alpha gradient แล้ว และถอดมาสก์สดออก ตรวจไฟล์ทดสอบและ 40s MP4 แล้วว่าตัวกลับมาครบ ห้ามนำมาสก์เดิมกลับมาโดยไม่ทดสอบ export
- `rig.json` บันทึก bbox ของ 14 ชิ้นบน canvas 2304×3072 อย่าเปลี่ยนขนาดเชิงเรขาคณิตตามไฟล์ภาพย่อ
- คำร้องหลักใช้ local forced alignment; เวลา token ย่อยของ B เป็นการแบ่งประมาณภายในกลุ่ม ไม่ใช่ทุกพยางค์ที่ฟังตรวจแล้ว
- เครื่องมือ browser เคยปฏิเสธการเปิดตัวเต็ม จึงตรวจภาพจริงด้วย CLI อย่าอ้างว่าเล่นตรวจใน browser ครบเพลงแล้ว
- `remotion.config.example.ts` ถูกเก็บเป็นตัวอย่าง; default config เดิมเคยมีปัญหา sandbox ขณะ build อย่าเปลี่ยนชื่อกลับโดยไม่จำเป็น
- CLI bundle ต้องใช้ `--out-dir=...`; positional output หลัง entry ถูกละเลยในเวอร์ชันที่ใช้
- ภาพ PNG ครบเลเยอร์ทำ Studio หนัก การ render export ยังเป็น 30 fps แม้ Studio เล่นไม่ทัน
- พรีวิว 540p ใช้สำเนาภาพครึ่งขนาดใต้ `work/preview-public` โดยเก็บ `layer-9.png` ความละเอียดเดิม ไม่แก้ต้นฉบับ
- สคริปต์นับ NAL ใน temp render ใช้คาดความคืบหน้าได้เฉพาะงานที่กำลังรัน ถ้างานจบแล้วอาจอ่าน temp งานเก่า ห้ามใช้แทนการตรวจไฟล์ผลลัพธ์

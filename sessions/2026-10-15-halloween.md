## เวอร์ชันสุดท้ายที่ส่งออก

- ความยาว 19.2 วินาที ที่ 30 fps
- แนวนอน: 1920×1080, composition `Halloween`
- TikTok: 1080×1920, composition `HalloweenTikTok`
- จังหวะเพลง 150 BPM ดรอปเริ่ม 6.4 วินาที
- ภาพซ่าทีวีช่วง 2.9–3.5 วินาที คร่อมการเปลี่ยนภาพที่ 3.2 วินาที พร้อมไฟช็อต
- เฉพาะภาพผมชมพูที่ปรากฏตั้งแต่วินาที 8 เป็นสีเทา
- ผีบินมีเฉพาะภาพปิดตาและร่างหลอน ไม่มีออร่าล้อมตัว
- เงาหนวดอยู่ตามขอบจอและขยับตามบีต โดยเว้นส่วนกลาง
- ข้อความแต่ละช่วงใช้ลูกเล่นต่างกัน คุมสีหม่น และเปลี่ยนเป็นเส้นขอบขณะขยาย
- DARK SIDE ที่ 14.4 วินาทีใช้พิมพ์ทีละตัวแล้ววิ่งเข้ากลาง
- คงการซูมและแรงกระชากในช็อตเดิม แต่เอาชุดทรานซิชันหนักที่ทดลองภายหลังออกแล้ว
- ใช้เบสกีตาร์และกีตาร์สังเคราะห์ ไม่ใช่ไฟล์อัดกีตาร์จริง

## ไฟล์และการเปิดงานต่อ

ไฟล์ TikTok ที่ส่งให้ผู้ใช้: `Downloads/Halloween-TikTok/Halloween-TikTok.mp4`

ซอร์ส Remotion ยังอยู่ในโปรเจกต์ท้องถิ่น `outputs/halloween/` มีทั้ง composition แนวนอนและแนวตั้ง บันทึกนี้ไม่ฝังพาธส่วนบุคคลในเครื่อง และไม่ได้อัปโหลดสื่อหรือซอร์สขึ้น GitHub

เริ่ม Studio จากโฟลเดอร์โปรเจกต์:
```powershell
npm run dev -- --no-open
```

คำสั่งส่งออก TikTok ที่ใช้:
```powershell
npx remotion render src/index.ts HalloweenTikTok ../Halloween-TikTok.mp4 --codec=h264 --crf=18 --pixel-format=yuv420p --concurrency=2
```

สร้างโฟลเดอร์ปลายทางก่อนคัดลอกไฟล์ และตรวจไฟล์จริงหลังส่งออก อย่ารายงานว่าเซฟแล้วจากการเริ่มเรนเดอร์เพียงอย่างเดียว

## วิธีเซฟเองจาก Studio

1. เลือก composition ที่ต้องการ เช่น HalloweenTikTok
2. เปิด Render และเลือก MP4 / H.264
3. ระบุชื่อไฟล์ แล้วเริ่มส่งออก
4. รอให้สำเร็จ และใช้ Open in Folder เพื่อเปิดตำแหน่งไฟล์
5. คัดลอกไฟล์ไปโฟลเดอร์ปลายทางที่ต้องการ

ชื่อปุ่มอาจต่างเล็กน้อยตามเวอร์ชัน Studio ที่ติดตั้ง
